      How the hype score (1–100) works

      Each card carries a hype score so you can compare the relative size of these tools at a glance — 90+ means major, widely-shared buzz; under 30 means a niche or local find. It is an estimate made when the item was added, not a live counter: there is no single public feed that adds up likes, stars and shares for every item, so the score weighs the signals that are visible for each one — whether it comes from an official source (Anthropic, Google, OpenAI, Microsoft, Vercel…), whether it is an open-source repo people star and fork on GitHub, the scale named in the post itself (models, skills, APIs, users), how established the product already is, and how much attention it got inside this group, including repeat saves and collections. Open any card with Read more to see the exact reasons behind its score. GitHub star counts are hard numbers, checked on the date shown.
